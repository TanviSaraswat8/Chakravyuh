# data/

Real and synthetic datasets for the real-data track. **No dataset files are committed**: only the
manifests in `registry/` (provenance, licence, access status, SHA-256). Everything else is fetched or
regenerated:

```bash
python scripts/fetch_real_datasets.py status
python scripts/fetch_real_datasets.py fetch imc25_smishing sp24_gateway_phishing
python scripts/validate_real_dataset.py --all
```

- `real/<type>/<id>/raw/` holds raw files, read-only and never edited. `.provenance.json` records where they came from (original, mirror or local download).
- `synthetic/` holds simulator and other synthetic data. It is never mixed with `real/`.
- `processed/` and `splits/` are derived and regenerated by the scripts. `reports/` keeps the latest validation and leakage results (counts only).

See `docs/REAL_DATA_STRATEGY.md` and `docs/DATASET_CATALOG.md`.
